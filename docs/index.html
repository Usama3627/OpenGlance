OpenGlance

A macOS system monitor for the menu bar

OpenGlance is an actively maintained fork of iGlance, a macOS system monitor for the menu bar. It keeps iGlance's GPLv3 license and contributor attribution while continuing development with a modernized interface and expanded dashboard.

Download for macOS

Features

  • CPU utilization & temperature
  • Memory monitoring
  • Network monitoring
  • Disk usage
  • Battery & fan monitoring
  • Configurable menu-bar items
  • Top resource-consumer dashboard
  • Light & dark appearance

Requirements

macOS 10.13 or later. Apple Silicon and Intel Macs are supported.

OpenGlance is licensed under the GNU GPLv3. A fork of iGlance by its contributors.
